# Procurement Dashboard — Power BI

## Project Overview
An interactive procurement dashboard developed using Microsoft Power BI to analyze purchase orders, supplier performance, material usage, and procurement trends.

## Project Objectives
- Monitor overall procurement performance.
- Analyze purchase amounts across plants and materials.
- Review supplier performance and supplier status.
- Analyze material groups, material types, and purchase quantities.
- Practice interactive reporting using slicers and visualizations.

## Key Features
- Procurement Overview
- Supplier Analysis
- Material Analysis
- KPI Cards for purchase amount, orders, suppliers, and materials
- Interactive slicers and page navigation
- Top 10 supplier and material analysis
- Purchase amount and quantity visualizations
